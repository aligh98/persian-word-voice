# صداگذاری واژه‌های فارسی با ElevenLabs

این اسکیل به ایجنت هوش مصنوعی کمک می‌کند فهرست واژه‌های یک اپ آموزش فارسی را با ElevenLabs صداگذاری کند. برای هر واژه یا اصطلاح یک فایل mp3 جدا ساخته می‌شود. فهرست می‌تواند صد واژه باشد یا چند هزار تا.

## چرا یک اسکیل جدا؟

اگر یک واژه‌ی فارسی را تنها به ElevenLabs بدهید، معمولاً درست می‌خواند. اما چند جا هست که اشتباه می‌کند، و در اپ آموزشی همین اشتباه‌ها به زبان‌آموز منتقل می‌شوند:

- **واژه‌هایی که چند تلفظ دارند.** «مهر» را مدل گاهی مِهر می‌خواند، گاهی مُهر. «ملک» و «کشتی» هم همین‌طورند.
- **حروف عربی در دیتابیس.** فهرستی که از اینترنت جمع شده، معمولاً «ي» و «ك» عربی دارد. به چشم فرقی نمی‌کند، ولی تلفظ را به سمت لهجه‌ی عربی می‌برد.
- **اعراب‌گذاری زیاد.** اگر روی همه‌ی حروف اعراب بگذارید، تلفظ عربی‌مآب می‌شود.
- **نوشتن واژه به شکل تلفظش.** مثلاً «مِن‌هِیسُل‌مَجمو» به‌جای «من‌حیث‌المجموع». مدل واژه را نمی‌شناسد و خشک و بی‌حس می‌خواندش.
- **مدل اشتباه.** فقط مدل‌های v4 و v3 فارسی دارند، و v3 روی واژه‌های کوتاه خوب کار نمی‌کند.

## اسکیل چطور کار می‌کند

قاعده‌های این اسکیل با گوش دادن به حدود ۲۵۰ نمونه، از فعل‌های ادبی تا اصطلاحات عربی‌تبار و واژه‌های یک‌هجایی، به دست آمده‌اند. خلاصه‌اش این است:

- واژه‌ای که فقط یک تلفظ دارد، بدون اعراب فرستاده می‌شود؛ حتی اگر سخت باشد، مثل «حتی‌الامکان».
- واژه‌ای که چند تلفظ دارد، فقط روی همان حرفی که تلفظ را عوض می‌کند اعراب می‌گیرد، مثل «مُهر» یا «مَلِک».
- حروف واژه هیچ‌وقت عوض نمی‌شوند. ابزار جلوی این کار را می‌گیرد.
- صدا با مدل `eleven_v4` و یک صدای فارسی‌زبان ساخته می‌شود.

## مراحل

۱. **خواندن فایل.** فایل اکسل (همه‌ی شیت‌ها)، CSV یا متنی خوانده می‌شود. ردیف‌های عنوان و واژه‌های تکراری کنار می‌روند و حروف عربی اصلاح می‌شوند. بعد تعداد واژه‌ها و هزینه‌ی تقریبی را می‌بینید.

۲. **پیدا کردن واژه‌های چندتلفظی.** ایجنت با کمک یک فهرست آماده و بررسی خود واژه‌ها، این موارد را پیدا می‌کند. تلفظ درست را از ستون معنی یا ترجمه یا از نام شیت تشخیص می‌دهد. اگر مطمئن نباشد، از شما می‌پرسد.

۳. **ساخت صدا.** اگر کار وسط راه قطع شود، مثلاً اعتبار تمام شود، از همان‌جا ادامه پیدا می‌کند و واژه‌های ساخته‌شده دوباره هزینه ندارند.

۴. **گوش دادن.** یک صفحه ساخته می‌شود که همه‌ی واژه‌ها را با پخش‌کننده نشان می‌دهد. کنار هر واژه می‌شود علامت «غلط یا ضعیف» زد و توضیح نوشت. آخر کار با یک دکمه فهرست این موارد آماده می‌شود و آن را برای ایجنت می‌فرستید.

۵. **اصلاح.** ایجنت اول اعراب واژه‌های گزارش‌شده را درست می‌کند، که هزینه‌ی اضافه ندارد. اگر باز هم خوب نشد و خودتان بخواهید، از جمله‌ی حامل استفاده می‌کند.

۶. **خروجی.** یک فایل mp3 برای هر واژه به‌اضافه‌ی `manifest.csv` که برای وارد کردن به دیتابیس اپ آماده است. اگر بخواهید، بلندی صدای همه‌ی فایل‌ها هم یکسان می‌شود تا در اپ صدای یک کارت بلندتر از کارت بعدی نباشد.

## جمله‌ی حامل

بعضی واژه‌ها تنها که گفته شوند، خوب ادا نمی‌شوند. برای این‌ها ایجنت یک جمله‌ی کوتاه می‌نویسد که با معنای همان واژه جور باشد و به خود واژه ختم شود. مثلاً:

> به کسی که همه‌چیز از دستش می‌افته و هر کاری رو خراب می‌کنه، می‌گن: «دست‌وپاچلفتی»

کل جمله ساخته می‌شود و بعد فقط خود واژه از آن بریده می‌شود. جمله به مدل کمک می‌کند واژه را با لحن درست بگوید.

این روش چون کل جمله را حساب می‌کند، حدود ده برابر بیشتر اعتبار مصرف می‌کند. برای همین فقط برای واژه‌هایی اجرا می‌شود که خودتان انتخاب کنید. قبلش سه جمله‌ی نمونه و هزینه‌ی تقریبی را می‌بینید.

## نصب

چیزهایی که لازم دارید:
- حساب ElevenLabs و کلید API آن
- پایتون ۳٫۹ یا بالاتر، و برای فایل اکسل: `pip install openpyxl`
- برنامه‌ی ffmpeg، که فقط برای جمله‌ی حامل لازم است
- یک ایجنت هوش مصنوعی که از Agent Skills پشتیبانی کند، مثل Claude Code

ابزار خط فرمان اسکیل (`scripts/fa_words.py`) بدون ایجنت هم اجرا می‌شود.

مراحل:

۱. پوشه‌ی `persian-word-voice` را در پوشه‌ی اسکیل‌های ایجنت بگذارید. برای Claude Code این پوشه `~/.claude/skills/` است.

۲. کلید API را به‌صورت متغیر محیطی تعریف کنید. اسکیل کلید را جایی ذخیره نمی‌کند.

   ```bash
   # Windows
   setx ELEVENLABS_API_KEY "your-key"
   # macOS / Linux
   export ELEVENLABS_API_KEY="your-key"
   ```

۳. یک صدا انتخاب کنید. بخش بعد را ببینید.

## انتخاب صدا

اسکیل با هر صدایی کار می‌کند. سه راه دارید:

- **صداهای آماده‌ی Voice Library.** در ElevenLabs به بخش Voices بروید و زبان را روی Persian بگذارید. چند صدا را گوش بدهید و یکی را که با اپ شما جور است به My Voices اضافه کنید. بعد Voice ID آن را کپی کنید و به ایجنت بدهید.
- **صدای کلون‌شده‌ی خودتان.** اگر صدای خودتان یا معلم اپ را در ElevenLabs کلون کرده‌اید، Voice ID همان را بدهید.
- **ساخت صدا با Voice Design.** با این قابلیت ElevenLabs، یک صدای تازه را با توصیف می‌سازید، مثلاً «زن جوان تهرانی، شمرده و واضح». Voice ID آن را بدهید.

اگر صدایی انتخاب نکنید، اسکیل از صدای پیشنهادی **Sara - Neutral Persian Female** استفاده می‌کند. این صدا باید در My Voices حساب شما باشد.

در تست‌ها، درست یا غلط بودن تلفظ به صدا بستگی نداشت. انتخاب صدا فقط سلیقه‌ای است. اسکیل صدایی را که بار اول انتخاب می‌کنید برای کل پروژه نگه می‌دارد، تا همه‌ی واژه‌ها با یک صدا ساخته شوند.

## از صفر تا تحویل، برای یک دیتابیس ۲ هزار واژه‌ای

۱. **نصب.** پوشه‌ی اسکیل را بگذارید، کلید API را تعریف کنید و Voice ID صدایی را که انتخاب کرده‌اید آماده داشته باشید.

۲. **شروع با نمونه.** به ایجنت بگویید:

   > فایل words.xlsx را با اسکیل persian-word-voice صداگذاری کن. ستون معنی‌ها «ترجمه» است. Voice ID این است: ... . اول ۲۰ واژه را بساز.

   آن ۲۰ واژه را گوش بدهید.

۳. **ساخت همه.** اگر راضی بودید، بگویید «همه را بساز». ایجنت هزینه را اعلام می‌کند (حدود ۱۲ هزار اعتبار برای ۲ هزار واژه). واژه‌های چندتلفظی را خودش اعراب‌گذاری می‌کند و اگر جایی شک داشته باشد، از شما می‌پرسد.

۴. **بازبینی.** صفحه‌ی `listen.html` را باز کنید و واژه‌های غلط یا ضعیف را تیک بزنید. «ساخت فهرست» را بزنید و متن را برای ایجنت بفرستید تا اصلاحشان کند.

۵. **تحویل.** بگویید «خروجی نهایی را با صدای یکسان بده». پوشه‌ای از فایل‌های mp3 به‌اضافه‌ی `manifest.csv` می‌گیرید که برای وارد کردن به اپ آماده است.

## هزینه

هر کاراکتر یک اعتبار ElevenLabs مصرف می‌کند. دو هزار واژه با میانگین شش حرف حدود ۱۲ هزار اعتبار می‌شود. هر واژه با جمله‌ی حامل بین ۴۰ تا ۸۰ اعتبار مصرف می‌کند. ایجنت قبل از هر اجرا هزینه و موجودی حساب را به شما می‌گوید.

## محدودیت‌ها

- فهرست واژه‌های چندتلفظی همراه اسکیل فقط موارد رایج را دارد. اگر دیتابیس ستون معنی یا ترجمه داشته باشد، ایجنت بقیه را راحت‌تر پیدا می‌کند.
- تأیید آخر با گوش شماست. ابزارهای تبدیل گفتار به متن فرق «مَرد» و «مُرد» را تشخیص نمی‌دهند.
- کیفیت صدا به صدایی که انتخاب می‌کنید و پلن حساب ElevenLabs بستگی دارد.
